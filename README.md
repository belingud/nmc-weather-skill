# nmc-weather-skill

中国气象局官方天气查询（中央气象台 nmc.cn 数据源）的 AI Agent skill。

实时天气 + 多日预报 + 空气质量 + 天气预警，**免费、免注册、免 API key，国内直连**。

## 功能

- 🌡️ 实时实况：温度、体感、湿度、降水、风力风向
- 📅 多日预报：未来 7 天逐日白天/夜间天气+温度
- 🏭 空气质量：AQI 指数与等级
- ⚠️ 天气预警：暴雨/台风/高温等官方预警
- 🗂️ 城市 code 本地缓存：查询过的城市秒回，无需重复扫描

## 使用方法

```bash
python3 scripts/weather.py "北京"    # 查北京
python3 scripts/weather.py "广州"    # 查广州（自动匹配省+城市）
python3 scripts/weather.py           # 默认查北京
```

## 城市名传参规则（重名处理）

中国有 23 组重名城市（市↔县/区/旗同名）。短名命中多个城市时脚本返回歧义错误（exit code 2），**不要自行猜测**，把候选列给用户确认后再查：

```bash
$ python3 scripts/weather.py "南昌"
[歧义] 「南昌」匹配到 2 个城市，请确认是哪一个：
  1. 江西省 南昌
  2. 江西省 南昌县
请回答带省市的全称（如「北京朝阳」），再查询。
```

- 查**南昌市**天气 → 传「南昌市」；查**南昌县**天气 → 传「南昌县」
- 查**朝阳** → 歧义，需传「北京朝阳」或「辽宁朝阳」
- 县名带不带"县"都行：`兰考` / `兰考县` 均可命中

## 数据精度

| 数据类型 | 更新频率 |
|:---|:---|
| 实况 | 约每 10 分钟滚动更新，对外发布约每小时 |
| 预报 | 每天发布多次（约 08/11/14/17/20 时） |
| 空气质量 | 约每小时 |

数据来源：中央气象台 nmc.cn 公开 JSON 接口，数据版权归中国气象局。

完整接口文档见 [`references/nmc-api.md`](references/nmc-api.md)。
